# 淋巴瘤领域模型（草案）

日期：2026-10-17。用途：为 G1/G3 提供共享词汇，说明**为什么界面长这样**。不替代指南，也不作为临床依据。

来源：用户提供的《淋巴瘤分类》表、`知识库/markdown/淋巴瘤分类结构化描述.md`、B/T 细胞指南覆盖亚型清单、`淋巴瘤药物清单分类.md`（自述依据 NCCN 2025 / CSCO 2024）。文中标注「待核」的条目尚未逐条对照原文。

## 1. 分类骨架

淋巴瘤的分类是**层级树**，不是一个平铺列表。界面必须能表达"我在树的哪一层"。

```
淋巴瘤
├── 霍奇金淋巴瘤（HL）
│   ├── 经典型（cHL，约 95%）
│   │   ├── 结节硬化型 NSCHL
│   │   ├── 混合细胞型 MCCHL
│   │   ├── 富于淋巴细胞型 LRCHL
│   │   └── 淋巴细胞消减型 LDCHL
│   └── 结节性淋巴细胞为主型（NLPHL；新版分类中已独立命名）
└── 非霍奇金淋巴瘤（NHL）
    ├── 成熟 B 细胞肿瘤
    │   ├── DLBCL（NOS / PMBCL / HGBL / EBV+ DLBCL）
    │   ├── 滤泡性淋巴瘤（1–2 / 3A / 3B）
    │   ├── 套细胞淋巴瘤（经典型 / 惰性型）
    │   ├── CLL/SLL
    │   ├── 边缘区淋巴瘤（MALT / SMZL / NMZL）
    │   ├── 淋巴浆细胞淋巴瘤（LPL / WM）
    │   ├── 伯基特淋巴瘤
    │   ├── 毛细胞白血病
    │   └── 浆细胞肿瘤（MM / POEMS）
    ├── 成熟 T/NK 细胞肿瘤
    │   ├── PTCL-NOS、AITL、ALCL（ALK+ / ALK−）
    │   ├── 结外 NK/T（鼻型）
    │   ├── 肝脾 T、肠病相关 T、ATLL
    │   └── 皮肤 T（MF / SS / pcALCL / PCFCL …）
    ├── 特殊部位（PCNSL、PTLD）
    └── 前体淋巴细胞（B-LBL / T-LBL）
```

设计约束：

1. **亚型是数据，不是代码分支**。新增亚型只改分类表，不新增页面。
2. 亚型名首次出现给中文全称 + 英文 + 缩写；之后可只用缩写。
3. 恶性程度分级（低/中/高）来自用户提供表，属**参考信息**，界面不据此给预后判断。

## 2. 诊断依据

| 层 | 内容 | 工作台怎么处理 |
| --- | --- | --- |
| 形态 | HE 染色、组织架构 | 抄录报告结论 |
| 免疫表型 | CD20/CD3/CD10/BCL2/BCL6/MUM1/Ki-67/EBER/PD-L1… | 逐项表格，可回原文页 |
| 遗传学 | FISH（MYC/BCL2/BCL6）、NGS、IG 重排 | 逐项；"未检测"原样显示 |
| 临床 | 部位、症状、影像、骨髓 | 进分期与病灶页 |

**双打击/三打击**：MYC 与 BCL2 和/或 BCL6 重排同时存在，属高级别 B 细胞淋巴瘤范畴。工作台只记录 FISH 结果，不做判读。

## 3. 分期（Lugano 2014）

| 期 | 定义 |
| --- | --- |
| I | 单个淋巴结区，或单个结外器官/部位（IE） |
| II | 横膈同侧 ≥2 个淋巴结区；或局部结外（IIE）+ 横膈同侧淋巴结区 |
| III | 横膈两侧淋巴结区；或脾受累 |
| IV | 弥漫/播散性结外受累（肝、骨髓等） |

修饰符：**A** 无 B 症状 / **B** 有 B 症状；**E** 结外；**S** 脾；**H** 肝；**M** 骨髓；**X** 大肿块（bulky，阈值按方案定义）。

B 症状：不明原因发热 >38℃、夜间盗汗、6 个月内体重下降 >10%。

**工作台立场**：分期由医生按影像判定，界面只记录结果与依据（哪次 PET、哪份骨髓报告）。

## 4. 预后评分

| 评分 | 适用 | 构成（公开信息） |
| --- | --- | --- |
| IPI | 侵袭性 NHL | 年龄 >60、LDH > ULN、ECOG ≥2、III/IV 期、结外受累 >1 处 |
| aaIPI | ≤60 岁侵袭性 NHL | LDH、ECOG、III/IV 期 |
| FLIPI | 滤泡性淋巴瘤 | 年龄 >60、III/IV 期、Hb <120 g/L、LDH > ULN、淋巴结区 >4 |
| MIPI | 套细胞淋巴瘤 | 年龄、ECOG、LDH、白细胞 |
| PIT | 外周 T 细胞淋巴瘤 | 年龄 >60、ECOG ≥2、LDH > ULN、骨髓受累 |
| IPS | 霍奇金淋巴瘤 | 7 项临床因素 |

**工作台立场（Q2 待确认）**：默认只记录"医生写了几分 + 出处"。若允许复算，必须：

1. 默认关闭，用户主动打开；
2. 结果固定标注「按公开公式复算，不是预后判断」；
3. 与医生记录不一致时，并列显示两个值，不自动取其一。

## 5. 疗效评估（Lugano 2014 + Deauville）

| Deauville | 定义 | 常见解读 |
| --- | --- | --- |
| 1 | 无摄取 | 代谢阴性 |
| 2 | 摄取 ≤ 纵隔血池 | 代谢阴性 |
| 3 | 摄取 > 纵隔但 ≤ 肝 | 多数方案中视为阴性，需结合临床 |
| 4 | 摄取明显 > 肝 | 残留摄取，需结合临床与活检判断 |
| 5 | 显著 > 肝和/或新病灶 | 进展风险高 |

**关键约束**：Deauville、CR/PR/SD/PD 都是**分类变量**，不能画成连续折线，也不能用"红绿"着色暗示好坏。界面用 5 格卡片 + 当前值标记 + 原文结论。

CT 为主的评估用 SPD（目标病灶直径乘积和）与 5 个新病灶规则；工作台一期只**记录**医生给出的数值，不做计算（Q9）。

## 6. 治疗线

```
一线 ── 方案（如 R-CHOP ×6）── 周期 1..n ── 评估 ── 结束/巩固
  ├── 未缓解/进展 → 二线（铂类、吉西他滨、双抗、CAR-T…）
  ├── 惰性 → 观察等待 / 单药 / 维持
  └── 移植（ASCT）作为巩固或挽救
维持 ── 长期口服（如 BTKi、来那度胺）或定期输注
```

工作台数据上要区分：

- **计划**（初始方案、计划日期、计划剂量）
- **实际**（实际给药日、实际剂量、延迟/减量原因）
- **状态**（进行中 / 完成 / 中止 / 换线）

## 7. 治疗相关风险（监测项，不是处置建议）

| 风险 | 何时看 | 工作台怎么呈现 |
| --- | --- | --- |
| 肿瘤溶解综合征 | 高负荷、治疗初期 | 尿酸、钾、磷、肌酐的同期记录 |
| 发热性中性粒细胞减少 | 每周期后 7–14 天 | ANC + 体温 + 是否住院 |
| HBV 再激活 | 含利妥昔方案、anti-HBc+ | HBsAg/anti-HBc/HBV-DNA 三次并列 |
| PJP | 长期激素/免疫抑制 | 预防用药记录（不评价方案） |
| 低丙种球蛋白血症 | 反复感染、IgG 低 | IgG 序列 + 感染记录 |
| 心脏毒性 | 蒽环类累积 | LVEF（若有） |
| 神经毒性 | 长春新碱/硼替佐米 | CTCAE 分级记录 |
| 生育力 | 治疗前 | 是否已咨询生殖医学（时间点关键） |

## 10. 与乳腺癌工作台的映射

| 乳腺 | 淋巴瘤 | 说明 |
