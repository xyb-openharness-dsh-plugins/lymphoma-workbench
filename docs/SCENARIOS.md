# 场景（S1–S12）

日期：2026-10-17。每条写清：谁、在什么时候、想回答什么、工作台给什么、**不给什么**、落在哪一页。

## S1 · 刚拿到病理，看不懂诊断名

- **谁**：38 岁男性，体检发现纵隔肿块，活检报告写「DLBCL, NOS」。
- **想回答**：这是哪一种？严重吗？下一步是什么？
- **给**：分型树定位、诊断原文、IHC/FISH 逐项、诊断日期与机构、"还需要确认的两件事"。
- **不给**：治愈率、生存期、"严不严重"的排序。
- **落点**：我的分型 / 分型档案、病理与分子。

## S2 · 治疗前评估与生育力

- **谁**：同一位，治疗前需完成 PET、骨髓、心脏超声、感染筛查。
- **想回答**：还有哪些检查没做？生育这件事什么时候谈？
- **给**：治疗前评估清单、每项完成状态、生育力保存的时间点提示。
- **不给**：是否必须做某项检查、生育力保存的具体方案。
- **落点**：我的分型 / 分期与病灶；心理支持 / 生育与家庭（生育只记时间点与咨询，并入治疗时间线）。

## S3 · 六个周期的执行与延迟

- **谁**：正在做 R-CHOP，第 2 周期后因粒缺发热延迟。
- **想回答**：原本第几周期？为什么延后？剂量改过吗？
- **给**：计划日/实际日两列、延迟天数、减量原因、不良事件分级。
- **不给**："应该减多少""要不要换方案"。
- **落点**：治疗历程 / 周期与用药。

## S4 · 粒缺发热那三天

- **谁**：家属在夜里发现 38.6℃。
- **想回答**：现在要不要去医院？该找谁？
- **给**：发热门槛文案（≥38.3 一次或 ≥38.0 持续 1 小时 → 联系治疗团队）、体温记录、"不是分诊规则"的说明。
- **不给**：是否急诊的判断、退热处理建议。
- **落点**：照护与症状 / 感染与发热。

## S5 · 中期 PET 的 Deauville 3

- **谁**：第 4 周期后，报告写 Deauville 3。
- **想回答**：这是好还是不好？要不要改方案？
- **给**：5 分定义、当前分标记、报告原文、医生当时的记录（"继续原方案，结束再评估"）。
- **不给**：把 3 分解释成"安全"或"危险"，不给改方案建议。
- **落点**：治疗历程 / 疗效评估。

## S6 · 结束评估与随访建立

- **谁**：6 周期结束，PET 写 Deauville 2。
- **想回答**：算治好了吗？以后多久复查一次？
- **给**：评估时间线、医生记录的 CR、随访节点、"节奏由医生定"。
- **不给**："已治愈""复发概率"。
- **落点**：治疗历程 / 疗效评估；复诊准备 / 复诊节奏。

## S7 · 惰性淋巴瘤的观察等待

- **谁**：52 岁女性，FL 3A，医生建议先观察。
- **想回答**：什么都不做对吗？什么时候才要治？
- **给**：观察等待专页、观察期记录项、复查节点、可以问的问题。
- **不给**："什么时候必须开始治疗"的阈值。
- **落点**：**看板（观察等待专属大卡）**；复诊准备 / 观察等待。

## S8 · 长期吃 BTKi 的第八个月

- **谁**：64 岁男性，MCL，维持期每日口服。
- **想回答**：漏服怎么办？心慌、牙龈出血要不要说？
- **给**：用药起止、漏服记录、不良反应分级、复查节点。
- **不给**："能不能停药""漏服要不要补"。
- **落点**：治疗历程 / 当前方案；照护与症状 / 症状与日常。

## S9 · 复发难治，开始找试验

- **谁**：45 岁女性，PTCL-NOS 二线后进展。
- **想回答**：有没有可以问的研究？要准备什么？
- **给**：线索列表（含期别、中心、状态"未核实"）、入组问题清单、可以带去问医生的问题。
- **不给**：排序、"你更适合哪个"、获益预测；**也不给药物说明**（机制、研发阶段、已发布数据不在工作台内，指向说明书与研究方案）。
- **落点**：临床试验 / 线索、入组问题。

## S10 · 换院与病理二次意见

- **谁**：准备去外地治疗，需要借切片。
- **想回答**：要带什么？会诊会不会改诊断？
- **给**：会诊清单（切片/蜡块/影像原片/治疗记录）、历史会诊记录、修正留痕规则。
- **不给**：是否会诊的建议、会诊结论的解读。
- **落点**：我的分型 / 会诊与二次意见。

## S11 · HBV 这条线

- **谁**：HBsAg 阴性、anti-HBc 阳性，正在用含利妥昔方案。
- **想回答**：为什么要吃抗病毒药？要查什么？
- **给**：三次 HBV-DNA 并列、anti-HBc 阳性的说明、预防用药记录。
- **不给**：预防用药的选择与疗程。
- **落点**：检查与指标 / 感染监测。

## S12 · 门诊前十分钟

- **谁**：任何一位，明天复查。
- **想回答**：我要问什么？带什么？
- **给**：问题清单（两类）、我的看法与担心、导出 Markdown、复查携带清单。
- **不给**：替用户判断哪些问题"更重要"。
- **落点**：复诊准备 / 就诊准备。
