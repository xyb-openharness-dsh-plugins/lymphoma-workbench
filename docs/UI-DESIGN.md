# 界面规格 · 小铃铛 v0.1.0

日期：2026-10-17。入口：[`prototypes/v0.1/index.html`](../prototypes/v0.1/index.html)。本地 CSS/JS，无外部库、无字体与网络请求。

## 1. 视觉基因（Taste 流程留档）

**情绪定位**：读者该感受到**「心里有数」**——不是被安慰，也不是被吓到，而是"这些事有人替我摆整齐了"。

| 项 | 选择 | 理由 |
| --- | --- | --- |
| 主基因 | 瑞士平面 / 包豪斯（moods/09 清晰理性） | 报告与数据为主，靠对齐与留白建立可信感 |
| 辅基因 | 吉卜力式圆润（只混一层） | Logo 本身是圆润的卡通铃铛；圆角与柔和浅紫底承接它，不另加装饰 |
| 不采用 | 渐变、玻璃拟态、彩虹图表、红绿好坏着色 | 与医疗场景的克制相冲突 |

一句话自检：**瑞士栅格打底、圆角与浅紫承接 Logo 的柔软，橙色只给行动。** 答得上，进入实现。

## 2. 视觉系统

| 项 | 值 | 说明 |
| --- | --- | --- |
| 品牌紫 | `#7C5CBF` | 主色、图表主序列、当前态 |
| 浅紫 | `#F3EFFC` | 选中底、hero 底、提示块 |
| 墨紫 | `#2E2438` | 正文与标题 |

| 纸色 | `#FAF8FD` | 页面底 |
| 数据副色 | 玫 `#A03D5C` / 青 `#2F6F66` / 赭 `#9A6410` / 蓝 `#4A6FA5` | 按**类别**分配，不按"好坏" |
| 圆角 | 14px（卡片）/ 9px（控件） | 全站两种，不混第三种 |
| 字体 | 系统中文（苹方/微软雅黑），正文 15px，大字 17px | 数字 `tabular-nums` |
| 层级 | h1 clamp(25–31) / h2 18 / h3 15 / 正文 15 / 注释 11.5 | 四级为主 |
| 阴影 | 仅 hover 抬升；卡片常态 1px 描边 | 不用阴影堆层次 |

**颜色规则**：一屏最多 4 个主色（紫、橙、墨、纸）+ 灰阶；数据色按类别固定，同一指标在所有页面同色。

## 4. 一图秀（核心）

### 4.1 与乳腺癌版本的三处差异

| 项 | 乳腺 v0.3 | 淋巴瘤 v0.1 |
| --- | --- | --- |
| 治疗条 | 手术/化疗/放疗/内分泌，按方案长条 | **按周期分段**（1–6 各一段）+ 评估节点（菱形） |
| 序列 | 16 个指标全部可画 | **只允许数值型**；Deauville/分期/ECOG 不进图 |
| 末点标签 | 奇偶错开 13px | **按 y 排序后强制最小间距 13px**，右端左锚定防裁切 |

### 4.2 结构与状态

```
[ 筛选 rail 238px ] [ 图表卡 + 详情条 ]
                     [ 指标卡片（按 6 类分组）]
```

```js
{ range:'3m'|'6m'|'12m'|'all', zoom:40–100,
  sel:[code] (≤4), toggles:{treatment, keypoints},
  pin:{code,date}|null, flipped:Set<code> }
```

选择变化只重绘 `#chart-panel` 与卡片，不重渲染整页（保留焦点）。

### 4.3 图表规则

1. 每条线按**该指标全部记录**的 min–max 归一化；图例写明范围与单位，并注明"不代表数值可比"。
2. **治疗条独立两行**：周期条在 y=36，评估节点在 y=64；数据区从 y=132 开始，关闭治疗节点后数据点位置不变。
3. 左侧标「周期 / 评估」两行，避免只看到 1–6 不知道是什么。
4. 末点数值：按 y 排序、强制 13px 间距、越界整体上移；靠右时 `text-anchor=end`。
5. 单点不连线；窗口内无点显示空态。
6. 只标末点，不给每个点加数字（会遮挡）。
7. 变化幅度：检验类用百分比，长度类用绝对值（mm/cm）。
8. 悬停/点击 → 详情条显示值、日期、来源；点 × 关闭。

### 4.4 Deauville 呈现

5 张卡片（1–5 分），当前值加紫边与「当前记录」标记；下方 5 段小标尺只高亮当前一格。

- **不连成折线**，不用红绿着色，不加"好转/恶化"字样。
- 卡片文案只写定义（"摄取 ≤ 纵隔血池"），不写"正常/异常"。
- 页脚固定一句："分数由核医学读片给出，工作台只记录原文。"

## 5. 指标卡（真 3D 翻转）

沿用乳腺 v0.3 的结构，修正了它的问题（内容必须与正面绝对叠放）：

```html
<button class="mcard" aria-pressed="false">
  <span class="mcard-inner">
    <span class="mface front">…</span>
    <span class="mface back">…</span>
  </span>
</button>
```

- 固定高度 188px，正反面 `position:absolute; inset:0`，翻转零位移。
- 每张卡状态存在 `Set`，互不影响；只切 class 与 `aria-pressed`，不重渲染。
- 背面：最近 5 次迷你折线 + 首末日期 + "仅回顾已核对记录，不做预测"。
- `prefers-reduced-motion` 下过渡降到 0.01ms。

## 6. 布局与响应式

面板参数沿用乳腺 D34：`businessSide=right`、`businessWidth=0.65`、`customFrame=false`，唯一来源 `lib/layout.js`。

**顶栏提示词对本项目的适用性判定（2026-10-20）**：`prompts/DSH-WORKBENCH-TOP-BAR.md` 只适用于 `customFrame=true`（宿主把原生会话节点交给插件排版的形态）。本项目是 A 方案标准分栏，分栏与顶栏由宿主绘制，**没有那条自建顶栏**，因此不套用它的三段式结构；顶栏相关约定按宿主形态执行（页面内顶栏仍遵守下面的换行与 nowrap 规则）。真要换成 B 方案时，才需要按该提示词实现自建顶栏。

- 侧栏 236px；≤900 折成整宽并横向滚动（10 项导航在窄屏变成一行可横滑的 chip）。
- **看板两列在 ≤1180 收成单列**：936px 业务区下左栏只有约 390px，两列会把指标卡挤成单列；收单列后右栏三张卡自动并排（`minmax(286px,1fr)`）。
- **顶栏在 ≤1180 允许换行**，且 `breadcrumb` / `status` 内文字强制 `nowrap`：否则「照护与症状」这类长页名会把顶栏按钮压成竖排。
- 宽表（周期表 6 列 / PET 表 6 列）在 936px 下整行跨列（`grid-column:1/-1`），不靠横向滚动藏列。
- ≤900：指标选择 `<details>` 默认收起；图表 `min-width:620px` 并提示可横滑。
- ≤600：版本 chip 让位（页脚常驻）；`path-row`/`token-row` 单列。

## 7. 实测（2026-10-17，Chrome 145 headless / macOS）

| 项 | 方法 | 结果 |
| --- | --- | --- |
| 视图渲染 | 27 个视图 × 3 档宽度（936 / 1440 / 390），共 **81 次** | 全部有 h1、内容非空、无 JS 异常 |
| 页面级横向溢出 | 每视图比对 `documentElement.scrollWidth` 与 `clientWidth` | **81 / 81 差值 = 0px** |
| 指标卡翻转 | 点击第一张卡 | `aria-pressed=true`，背面文本可读（"最近 5 次 · 肿瘤…"） |
| 时间窗联动 | 全期 → 近 3 月 | 数据点 19 → 6 |
| 画像切换 | 周先生 → 陈女士 | 侧栏姓名与"52 岁 · 滤泡性淋巴瘤 3A"同步 |
| hash 前进/后退 | `history.back()` | 从随访回到一图秀，标题同步 |
| 版本号 | 顶栏 / 页脚 / 关于 | 三处均 `v0.1.0`；`npm run check` 核对 5 处 |

**负向对照已补**（2026-10-17，`npm run probe:render -- --negative`）：向 `<body>` 注入 2000px 宽元素后溢出读数为 **1064px**，检测确认有效（936px 视口下 2000 − 936 = 1064）。

复跑命令：`npm run probe:render`（或加 `--negative`），需本机 Chrome；不进 `npm run check`，因为依赖浏览器。

## 9. 已知取舍

- 亚型树只画到当前亚型所在路径，不展开全树；全集移到「分型库」以**表格**呈现（24 行可筛选），不用树。树适合"我在哪"，表适合"还有哪些"。
- 一图秀只收数值指标，因此"疗效"不在图里——它在「疗效评估」页单独成块。这是有意的，不是缺功能。
- 观察等待没有做成一级入口（D20）：惰性画像在**看板**出专属大卡，其余画像看不到这块。
- 药物资料整体不在工作台内（D22），因此试验线索卡只有药名与期别，没有机制/阶段/数据。
- 第 2 线（及以后）目前只有空态，没有演示数据；空态是真实交付的一部分，不是占位。
- 五套演示画像只改元数据与关键卡，指标序列共用 DEMO-1；界面已明写。
