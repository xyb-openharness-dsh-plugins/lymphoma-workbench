# 小铃铛品牌素材

用户于 2026-10-17 提供小铃铛 Logo（文件名 `小铃铛logo.jpg`，1921×1921 JPEG），明确要求作为本工作台 UI 色系基准。原件保存为 [brand/lymbell-logo-original.jpg](brand/lymbell-logo-original.jpg)，**未裁切、未重绘、未变形**。

使用授权范围为本次工作台 UI 设计；公开使用与商用授权未在本次范围内确认，对外发布前需单独确认。

## 派生文件

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| `lymbell-logo-original.jpg` | 1921×1921 | 唯一原件，只在仓库根 `assets/` 保存 |
| `brand/lymbell-mark-96.png` | 96×96 | 侧栏图标 1x（仅图形，不含品牌字） |
| `brand/lymbell-mark-192.png` | 192×192 | 侧栏图标 2x（`srcset`） |
| `brand/apple-touch-icon.png` | 180×180 | 桌面 / 收藏图标 |
| `brand/lymbell-logo-full.png` | 560 宽 | 「关于」弹窗的完整竖版（含品牌字） |

原型另存一份到 `prototypes/v0.1/assets/brand/`——**页面只能引用所在目录内的相对路径**。`../../assets/...` 在 `file://` 下能显示，但经 HTTP 预览会被规范化到根外并 404（乳腺癌工作台 v0.3 的真实事故）。

## 生成方法（可复现）

图形区域裁切：`sips -c 1190 1460 --cropOffset 175 245` 后再补白成正方形，然后缩放到目标尺寸。品牌字区域不进入方形图标，避免 48px 下文字糊成一团。
