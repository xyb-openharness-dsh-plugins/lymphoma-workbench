## 4. 本轮修掉的问题

| 现象 | 根因 | 修法 |
| --- | --- | --- |
| 顶栏按钮被压成竖排（「资料目录 / 已激活」上下叠） | 页名变长（「照护与症状」）+ 5 个按钮，`nowrap` 缺失导致 flex 挤压 | `breadcrumb`/`status` 内文字 `nowrap`；≤1180 顶栏允许换行 |
| 936px 下看板两列被挤：指标卡变单列、右侧卡片标题竖排 | 业务区 936 时左右列只有约 390 / 280px | ≤1180 两列收单列，右栏三卡由 `minmax(286px,1fr)` 自动并排 |
| 4 张入口卡在 936px 变成 3+1 | `minmax(206px,1fr)` 算出 3 列 | 提到 `238px`，936 → 2×2，1440 → 4 连排 |
| 看板 4 张指标卡变 3+1 | `.metric-grid` 在 ~700px 算出 3 列 | 看板内固定 2 列（2×2） |
| 删页面时误删 `pageSupportBlood`，整页白屏 | 按函数区间整段替换，区间跨过了相邻函数 | 补回函数；探针的 `JS 异常` 检查当场报出 `ReferenceError` |
| 页脚/顶栏链接仍指向 `#followup`、`#support` | 改页 id 后旧链接失效（回落到看板） | 全量替换为 `#review`，并把子页名同步为「复诊节奏」 |
