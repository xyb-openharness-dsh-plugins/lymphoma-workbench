### 定义

淋巴瘤是起源于淋巴细胞（B 细胞、T 细胞、NK 细胞）的恶性肿瘤的统称，按大类分霍奇金淋巴瘤（HL）与非霍奇金淋巴瘤（NHL）。它不是一个病，而是一棵层级树——「我在树的哪一层」决定了后面所有记录的含义。

分类口径是一棵层级树：霍奇金（经典型 cHL 的结节硬化型、混合细胞型、富于淋巴细胞型、淋巴细胞消减型，以及结节性淋巴细胞为主型 NLPHL）；非霍奇金里分成熟 B 细胞肿瘤、成熟 T/NK 细胞肿瘤、特殊部位（PCNSL、PTLD）与前体淋巴细胞（B-LBL / T-LBL）。病理亚型是这棵树的叶子：本项目「分型库」按 NCCN 有独立诊疗路径的亚型筛出 24 项（B 细胞 14 / T-NK 8 / 霍奇金 2）。**「分型」与「分期」不是一回事**：分型看病理（形态、免疫表型、遗传学），分期看病灶分布，用的是 Lugano 2014；两者不互推。

**来源**：[WHO · 造血与淋巴组织肿瘤分类（第 5 版 / WHO-HAEM5，IARC 出版页）](https://publications.iarc.who.int/Book-And-Report-Series/Who-Classification-Of-Tumours/Haematolymphoid-Tumours-2024) · 未取得原件，据二次来源 · 页码待核 ｜ [Lugano · Lugano 分类（2014）](https://rs.yiigle.com/cmaid/1671095) · 未取得原件，据《中国淋巴瘤诊疗指南（2026版）》转引 · 页码待核

### 目前治疗全景概要

按 Lugano 分期与线序列出指南里出现过的手段类别，不含剂量、疗程与适用条件。

- **局限期（Lugano I–II 期）**：系统治疗（以联合化疗方案为主，方案按亚型不同）／受累部位放疗（部分亚型与期别列为治疗组成）／观察（部分惰性亚型在特定情形下先不治疗、定期复查）。
- **晚期（Lugano III–IV 期）**：系统治疗（化疗、靶向、免疫分别列出，线序按亚型区分）／自体造血干细胞移植（特定亚型与线序）／细胞治疗（如 CAR-T，特定亚型与线序，国内可及性需单独核实）。
- **复发 / 难治**：二线及以后系统治疗（候选清单，不是排序）／移植与细胞治疗的再评估（按年龄、体能、器官功能判断）／临床研究（被列为正式选项，不是最后手段）。
- **贯穿全程**：疗效评估（Lugano 2014 结合 Deauville 评分，只抄报告原文）／复查节奏（只整理「约在哪天、做了没有」）。

以上是文献与指南里列出的手段，按病期与线序排列，**不代表任何一项适合你**。选哪一个，这一句需要问你的医生。

## 为什么淋巴瘤工作台不能照搬乳腺癌

| 维度 | 乳腺癌 | 淋巴瘤 |
| --- | --- | --- |
| 起点 | 一个器官、一套分期 | **亚型决定一切**：>80 个亚型，治疗与随访各不同 |
| 分期 | TNM | **Lugano**（结内/结外/脾/肝/骨髓 + A/B 症状） |
| 疗效 | 影像大小 + 标志物 | **PET-CT + Deauville 5 分**（分类变量，不能画折线） |
| 治疗 | 手术 → 化疗 → 内分泌 | **方案组合 + 线数**（R-CHOP、ABVD、BTKi 长期吃、CAR-T） |
| 状态 | 术后康复、上肢 | **观察等待、维持治疗、移植、复发难治** |
| 风险 | 淋巴水肿、骨健康 | **肿瘤溶解、粒缺发热、HBV 再激活、PJP、IgG 低下** |

所以本项目的核心页不是「术后上肢」，而是**我的分型**与**疗效评估**；一图秀的中心不是"把 16 个指标画在一起"，而是"把治疗线、评估节点与可量化指标放回同一段时间"。

## 产品立场（沿用乳腺工作台 D16，本项目 D3）

诊断、分期、疗效判读与处置全部归医生。工作台提供的是**边际信息**：把散落的病理、影像、化验与用药记录归拢、标出处、按时序摆好，让每次沟通有据可查。

- 用户的判断与担心按一条信息记录（`viewpoint`），标注「不是医生结论」，不进趋势、不进摘要事实区。
- 工作台**不判读**病理与影像，不把 Deauville 分数改成"好/坏"，不把 IPI 算成预后判断。
- 临床试验线索只做备忘，**不推荐、不排序、不预测获益**。
